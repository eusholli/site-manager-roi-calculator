# Rakuten Site Manager ROI Calculator

A web-based calculator that demonstrates the financial and operational benefits of using Rakuten Site Manager for project management.

## Overview

The Rakuten Site Manager ROI Calculator is a static web application that helps potential customers understand the value proposition of Site Manager. By inputting a few key metrics about their current operations, users can immediately see projected savings in both time and money.

## Features

- **Simple Interface**: Easy-to-use form with intuitive inputs
- **Detailed Calculations**: Computes project speed savings, cost savings, and labor/admin savings
- **Visual Results**: Displays savings with clear charts and highlighted figures
- **Responsive Design**: Works on desktop, tablet, and mobile devices
- **No Dependencies**: Built with vanilla HTML, CSS, and JavaScript

## Calculations

The calculator performs the following key calculations:

1. **Project Speed Savings**:
   - New project duration based on efficiency improvements
   - Total weeks saved annually across all projects

2. **Cost Savings**:
   - Direct project cost savings based on cost reduction percentage
   - Admin/labor cost savings from reduced manual work

3. **Return on Investment (ROI)**:
   - Calculated as total annual savings relative to total project costs

## Visualizations

- **Savings Breakdown Pie Chart**: Shows the proportion of cost savings vs. admin/labor savings
- **Project Duration Bar Chart**: Compares before and after project durations

## Usage

Simply open `index.html` in a web browser. No installation or build process required.

## Deployment

The calculator is designed to be deployed on GitHub Pages:

1. Push the repository to GitHub
2. Enable GitHub Pages in the repository settings
3. Select the main branch as the source

## Development

To modify or extend the calculator:

1. Edit `index.html` for structure changes
2. Modify `style.css` for styling updates
3. Update `script.js` for calculation or behavior changes

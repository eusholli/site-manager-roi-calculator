# Product Context: Rakuten Site Manager ROI Calculator

## 1. Problem Solved

Managing numerous distributed sites or large-scale projects (e.g., in telecom, energy, construction) involves significant complexity, cost, and potential for delays. Key pain points include:

-   **Inefficiency:** Manual tracking, reporting, and coordination consume valuable administrative and project management time.
-   **High Costs:** Labor, materials, and delays contribute to substantial project expenses. Inefficiencies exacerbate these costs.
-   **Delays:** Lack of real-time visibility and coordination often leads to projects exceeding deadlines, impacting revenue and customer satisfaction.
-   **Difficulty Quantifying Value:** Prospective customers of solutions like Rakuten Site Manager may struggle to easily quantify the potential financial benefits and operational improvements.

## 2. How It Should Work (User Experience Goals)

The ROI Calculator should provide a simple, compelling way for potential Site Manager users to understand its value proposition:

-   **Ease of Use:** Users should be able to input a few key metrics about their current operations (site volume, costs, timelines) and immediately see projected savings. The interface must be intuitive, requiring minimal explanation (target 5-10 input fields).
-   **Clarity and Impact:** The results (savings in dollars and time, ROI percentage) must be presented clearly and prominently. Visual elements like charts and large numbers should emphasize the positive impact of Site Manager.
-   **Credibility:** While simple, the calculations should be based on realistic assumptions and clearly defined logic (as outlined in `calculator.md`). Default values should represent typical industry scenarios.
-   **Action-Oriented:** The calculator should naturally lead the user towards engaging further with Rakuten Symphony, facilitated by a clear call-to-action link.
-   **Self-Explanatory:** The tool should function as a standalone demonstration of value, understandable without needing a live demo or extensive background knowledge.

## 3. Target Audience

-   Decision-makers (Executives, Directors, VPs) in industries managing distributed sites/projects.
-   Project Managers and Operations Leaders evaluating tools to improve efficiency and reduce costs.
-   Sales and Marketing teams at Rakuten Symphony using the tool as a demonstrative asset.

## 4. Core Value Proposition Demonstrated

The calculator aims to prove that investing in Rakuten Site Manager yields significant, measurable returns by:

-   Reducing project completion times.
-   Lowering overall project costs.
-   Decreasing manual administrative overhead.
-   Improving on-time project delivery rates.

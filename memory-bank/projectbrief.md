# Project Brief: Rakuten Site Manager ROI Calculator

## 1. Core Objective

To create a web-based Return on Investment (ROI) calculator for Rakuten Site Manager. This tool aims to clearly demonstrate the financial and operational benefits of using Site Manager to potential customers.

## 2. Key Requirements

-   **Functionality:** Calculate ROI based on user inputs related to project volume, costs, duration, and efficiency gains expected with Site Manager.
-   **Platform:** Static web application (HTML, CSS, JavaScript).
-   **Hosting:** Deployable on GitHub Pages.
-   **Design:** Fully responsive design adhering to the Rakuten Symphony visual guidelines provided in `RS_design.json`.
-   **User Experience:** Simple, intuitive, self-explanatory interface. Maximize the visual impact of the calculated savings.
-   **Output:** Display key metrics (cost savings, time savings, ROI %) clearly, using charts and highlighted figures.
-   **Call to Action:** Include a clear link to the Rakuten Symphony contact form.

## 3. Source Documents

-   `calculator.md`: Defines input fields, calculation logic, output requirements, and hosting instructions.
-   `RS_design.json`: Provides specific color palettes, typography, and component styling guidelines based on Rakuten Symphony's branding.

## 4. Scope

-   Develop the front-end application (HTML, CSS, JS).
-   Implement the calculation logic as specified.
-   Style the application according to the design specifications.
-   Ensure responsiveness across common device sizes (desktop, tablet, mobile).
-   Prepare the application for deployment on GitHub Pages.

## 5. Exclusions (Unless specified later)

-   Backend data storage or user accounts.
-   Advanced features like PDF export, multi-language support, or scenario saving (initially).
-   Integration with other Rakuten Symphony systems.
